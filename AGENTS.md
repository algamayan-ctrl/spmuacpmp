# Project progress tracking

The user requires a persistent progress tracker for this project.

- At the start of a task or resumed session, read Current progress in docs/UI-ADMIN-REVISION-TRACKER.md.
- Keep the current step and next action accurate. Update the tracker after material findings, completed checks, changes in blockers, and before each handoff or final response.
- Distinguish implementation, automated tests, browser verification, and verification of the running application. Mark a step complete only when its stated acceptance checks have passed.
- Include a concise status and the tracker link in handoffs. Preserve historical results and tasks paused by the user.
